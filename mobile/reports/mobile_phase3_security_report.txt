2. REMOVE PRODUCTION API URL OVERRIDE & HARDENING:
--------------------------------------------------------------------------------
- Hardened Endpoint Resolution (`src/utils/networkSecurity.js`):
  * Production mode (`!__DEV__` or `NODE_ENV === 'production'`):
    - HTTPS is strictly mandatory (`protocol === 'https:'`).
    - Hostname must match approved production allowlist (`APPROVED_PRODUCTION_HOSTS`: `api.marketplace.eg`).
    - Malformed, insecure, or unknown destinations fail closed.
    - Missing production URL safely defaults to approved HTTPS endpoint `https://api.marketplace.eg/api`.
    - Never falls back to localhost or 10.0.2.2 in production.
  * Development mode:
    - Allows localhost, 127.0.0.1, and 10.0.2.2 loopback.
    - Private LAN IPs (192.168.x.x, 10.x.x.x) require explicit `ALLOW_CLEARTEXT === '1'`.
- Request Interceptor Destination Validation:
  * Blocks pseudo-protocols (`javascript:`, `file:`, `data:`).
  * Validates absolute URLs against approved host allowlist.

3. ANDROID CLEARTEXT TRAFFIC PROTECTION:
--------------------------------------------------------------------------------
- `android:usesCleartextTraffic`:
  * Enforced to `"false"` in production `AndroidManifest.xml`.
  * Configured via `plugins/withMobileSecurity.js`.
- Production Build Guard (`app.config.js`):
  * Explicit guard throws build exception if `ALLOW_CLEARTEXT=1` is present during a production build.
  * Explicit guard throws build exception if `EXPO_PUBLIC_API_URL` starts with `http://` in production.
- Android Network Security Config (`network_security_config.xml`):
  * Generated under `android/app/src/main/res/xml/network_security_config.xml`.
  * `<base-config cleartextTrafficPermitted="false">` denies cleartext HTTP application-wide.
  * `<domain-config cleartextTrafficPermitted="false">` explicitly protects `api.marketplace.eg` and `marketplace.eg`.
  * Linked via `android:networkSecurityConfig="@xml/network_security_config"` in `AndroidManifest.xml`.
