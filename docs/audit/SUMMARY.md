## 1. لوحة المؤشرات التنفيذية (Executive Dashboard)

### 1.1 إحصائيات المستودع والمكونات البرمجية
- **الباك إند (`backend/`)**:
  - معمارية نظيفة (Clean Architecture) مبنية بـ .NET 10 و C# 13 عبر 4 مشروعات (`Domain`, `Application`, `Infrastructure`, `API`).
  - **108 مسارات API** عبر 20 وحدة تحكم (Controllers): 13 مسار أدمن، 23 مسار بائع، 15 مسار مشتري، 29 مسار توثيق عام، 28 مسار مجهول.
  - **16 ترحيلاً لقاعدة البيانات (EF Core Migrations)** على PostgreSQL مع انطباق تام ومثبت لنموذج البيانات الحالي (`has-pending-model-changes` = false).
- **تطبيق الموبايل (`mobile/`)**:
  - React Native 0.88.0 مع Expo 58.0.0 و React 19.3.0 وتنسيقات Tailwind (twrnc).
  - 8 شاشات للمشتري، 7 شاشات للبائع، شاشتان للأدمن، 5 شاشات للمصادقة، شاشة قفل البصمة.
- **لوحة الويب (`admin-web/`)**:
  - React 19.2.8 مع Vite 6.4.4 و TailwindCSS 4.3.3.
  - **خطر تشغيلي حاسم**: المجلد عبارة عن Directory Junction محلي غير متتبع نهائياً داخل Git (`git ls-files` = 0).

### 1.2 حقيقة التغطية الاختبارية (Test Coverage Reality)
- **غياب اختبارات C# المدمجة**: لا يوجد **أي مشروع اختبار C# قياسي** (`*Tests.csproj`, `xUnit`, `NUnit`) داخل ملف الحل [`Marketplace.slnx`](file:///d:/Backend/marketplace/backend/Marketplace.slnx). أمر `dotnet test` لا ينفذ شيئاً.
- **سكربتات Node.js الخارجية**: يعتمد المشروع كلياً على **34 سكربت اختبار Node.js**:
  - 12 سكربتاً تتصل بسيرفر محلي متصل بـ PostgreSQL.
  - 7 سكربتات محاكاة (Mock) في الذاكرة.
  - 15 سكربت فحص نصوص ثابتة ومحاكاة واجهات.
- **نزاهة الاختبارات**: تتضمن بعض سكربتات الـ "Postgres" (مثل `test_batch1_verification_postgres.js`) عمليات فحص نصوص ثابتة لملفات الواجهات عبر `fs.readFileSync` محتسبة كاختبارات قاعدة بيانات حية، مع وجود فحصين فاشلين في التقرير الأخير (`test_account_deletion_mock.js` و `test_verification_pack_postgres.js`).

## 5. خطة العمل المباشرة للمطور الفردي (Next Steps: Milestone 0 Day-by-Day)

للبدء الفوري في تصحيح المنصة وتأهيلها للتجربة التجريبية لـ 10 مستخدمين، يجب تنفيذ المهام التالية بالترتيب الدقيق:

- **اليوم 1**: فك ارتباط Junction لمجلد `admin-web` ودمج كود لوحة التحكم بالكامل داخل المستودع وتأكيد تتبعه عبر Git (`TSK-M0-01`).
- **اليوم 2**: تعديل `ConsoleEmailSender.cs` و `ConsoleSmsSender.cs` و `ConfigurableHttpSmsSender.cs` لحجب أكواد OTP وأرقام الهواتف من السجلات (`TSK-M0-02`).
- **اليوم 3**: توليد ترحيل EF Core جديد لتحويل فهرس `IX_Orders_BuyerId_IdempotencyKey` إلى `UNIQUE INDEX` للقيم غير الفارغة (`TSK-M0-03`).
- **اليوم 4**: إغلاق مسار البائع `PUT /api/orders/{id}/status` وتطبيق حماية القفل التزامني على `CancelOrderAsync` في `OrderService.cs` (`TSK-M0-04`, `TSK-M0-05`).
- **اليوم 5**: رفع سقف الـ Rate Limiting في `Program.cs` إلى 180 طلب/دقيقة للطلبات العامة (`TSK-M0-06`)، ودعم الأرقام المشرقية في `EgyptianPhoneNormalizer.cs` (`TSK-M0-07`)، وتحديث وثيقة `docs/DEPLOY.md` (`TSK-M0-08`).
